How an ADC samples and quantizes a signal

The black curve is the analog input. The ADC checks it only at the clock ticks (silver). At each tick it reports which voltage bin the signal is in, then holds that code until the next tick (gold). Between ticks, the signal can move into a new bin, but the output won't change until the next sample.

Model. 0–3.3 V input range, N bits → 2N codes, LSB = 3.3 V / 2N. Code = floor(Vin / LSB), clamped to 0…2N−1. The gold step is drawn at the center of the reported bin. The dashed silver segment at each sample shows the quantization error, which is at most ½ LSB.

Things to try. Set it to 2-bit to see coarse quantization, then 5-bit to see finer steps. Lower the sample rate to 1–2 Hz: the signal crosses several bins between readings and the output jumps. That is a sampling-rate problem, not a resolution problem.

Noise. The noise slider adds random Gaussian noise (σ = slider/3, clipped at ±slider) to the input. The dashed gray curve is the clean signal. Compare the noise to the LSB in the tiles. When the noise is much smaller than one LSB, the codes barely change. At 4–5 bits with ±100 mV or more, readings near a bin edge flicker between neighboring codes, so the extra resolution mostly digitizes noise. Near the top or bottom of the range, noise can push the input past 0 or 3.3 V, and the ADC saturates at the end code. Reset generates a new noise pattern.
