E2 Week 1 (Course Week 5) · Lecture

What a Good Prediction Looks Like — Committing Before You Look

Directly primes students for the Tier 1 Phase 2 prediction memo, which they will begin in this week's lab session. The lecture opens with the distinction that separates a prediction from a guess: a prediction is falsifiable, committed in writing before data is seen, and derived from reasoning that can be evaluated independently of whether the prediction turned out to be correct. The lecture walks through the five elements that every defensible prediction must contain — (1) system response features with committed specific values or ranges (not vague directional claims), (2) an uncertainty estimate derived from the available sensor specs using the propagation methods from E1 W2, (3) a sketch of the expected output with axes, units, and uncertainty bounds drawn before any data is seen, (4) a ranked list of dominant uncertainty sources with estimated magnitudes, (5) a named acceptance criterion stated as a numerical threshold. Each element is illustrated using a worked example from an experiment the class has not used — the instructor walks through how to extract a prediction from theory and specs alone, without touching hardware. **The grading philosophy:** This lecture must communicate the Phase 2 grading standard explicitly: a prediction that turns out to be wrong but was derived from sound physical reasoning and complete committed analysis is more valuable than a prediction that turns out to be right but was derived from vague intuition. The goal of pre-commitment is not to be correct — it is to be honest about what you knew before you saw the data, so the discrepancy teaches you something. This philosophy echoes through E2 and E3: it is the professional norm for test engineers, and students should hear it named clearly before Phase 2 begins.
