Procedure - Locomotive Crank: Kinematic Model Validation

Overview

This lab investigates a locomotive crank apparatus: a motorized disk drives a rigid connecting bar, which moves a collar along a vertical slide. Students analyze rotary encoder and linear potentiometer data collected at multiple motor voltages, then compare measured collar velocity against a geometry-based kinematic model.

The lab has two distinct parts that must be done in sequence:

  1. Pre-Lab: Review and verify the provided kinematic derivation, then implement the MATLAB model.
  2. Analysis Lab: Load provided data, calibrate/interpret the measurements, compare model and experiment, and analyze residuals.

This 3501 version should focus on measurement, model implementation, residual analysis, and uncertainty/error-source reasoning. It should not require students to generate a full derivation from scratch.

Part 3 - Experimental Procedure Context

The catalog includes a detailed Summer 2026 procedure and Spring 2025 appendix. The important procedure points for the student-facing 3501 analysis are:

  1. Verify the MyDAQ is recognized as MyDAQ1 in NI MAX.
  2. Connect the power supply with correct polarity so the crank rotates counterclockwise.
  3. Set the current limit to 5 A.
  4. Do not exceed 11 V.
  5. Place the collar at its lowest position before starting the VI; this establishes the theta reference.
  6. Calibrate the potentiometer using measured slide displacement and high/low voltage readings.
  7. Record data for roughly 8-10 rotations at each selected voltage.
  8. Save files using a voltage-aware naming convention such as Test2_5pt6V.

For ASEN 3501, students may work from provided data rather than collecting live data. If live data collection is used, the same safety and setup constraints above apply.

Part 4 - Data Analysis Workflow

  1. Load each data file.
  2. Convert or normalize theta so it starts in a consistent range and increases continuously.
  3. Use only the first six revolutions unless the instructional team specifies otherwise.
  4. Compute model velocity at the experimentally measured theta values. Do not evaluate the model only on a separate linspace grid when computing residuals.
  5. Plot measured collar velocity and modeled collar velocity versus theta for each voltage.
  6. Compute signed residuals:

residual = v_exp - v_mod
  1. Plot residuals versus time and versus theta.
  2. Compute mean and standard deviation of residuals for each voltage.
  3. Discuss whether residual structure looks random or systematic.

Residuals versus theta are especially important because mechanical play in the linkage can create periodic error locked to crank angle.

Model / Derivation

Provided Unverified Derivation - Locomotive Crank Kinematics

Student Instruction

The following derivation is provided so that this lab can focus on data analysis and model validation rather than deriving the crank-slider kinematics from scratch. Treat it as provided but unverified. Review the geometry, sign conventions, and algebra before using the final equation in your analysis.

Verification is the right word here: students are not being asked to create an original derivation, but they are responsible for checking whether the provided derivation is internally consistent and appropriate for the data they analyze.

Geometry And Variables

The apparatus consists of:

  • A disk rotating about fixed point O
  • A crank pin A located a radius r from O
  • A rigid connecting bar of length l from A to the sliding collar point B
  • A vertical slide for B
  • A horizontal offset d from the vertical slide to the disk centerline

Variables:

SymbolMeaning
thetaDisk angle
betaConnecting-bar angle from the vertical slide
omega_DDisk angular velocity, theta_dot
omega_BConnecting-bar angular velocity, beta_dot
v_B_yVertical velocity of the collar

The derivation source PDF is retained in derivation/ASEN2003 Lab3 Locomotive Derivation.pdf.

Position Relations

Using unit vectors i to the right and j upward, the crank-pin position relative to O is written as:


r_A = -r sin(theta) i + r cos(theta) j

The collar point B relative to A is:


r_B/A = -l sin(beta) i - l cos(beta) j

The horizontal constraint gives:


sin(beta) = (d - r sin(theta)) / l

Students should check this relation against the physical geometry and the chosen positive direction for theta.

Bar Angular Velocity

Differentiate the horizontal constraint:


sin(beta) = (d - r sin(theta)) / l

which gives:


cos(beta) beta_dot = -(r/l) cos(theta) theta_dot

Since theta_dot = omega_D,


omega_B = beta_dot = -(r cos(theta) / (l cos(beta))) omega_D

The derivation PDF also reaches an equivalent magnitude relationship through rigid-body velocity relations. Students should verify the sign convention they use in MATLAB, especially if their theta direction or positive collar velocity direction differs from the diagram.

Collar Velocity

The collar is constrained to move vertically, so the horizontal velocity of B is zero. The vertical velocity follows from differentiating the B position or from the two-point rigid-body velocity relation.

Starting from:


r_B = d i + (r cos(theta) - l cos(beta)) j

differentiate:


v_B_y = -r sin(theta) theta_dot + l sin(beta) beta_dot

Substitute theta_dot = omega_D and the expression for beta_dot:


v_B_y = -r omega_D sin(theta)
 - r omega_D cos(theta) tan(beta)

Final compact form:


v_B_y = -omega_D r [sin(theta) + cos(theta) tan(beta)]

with:


beta = asin((d - r sin(theta)) / l)

Verification Checklist

Before using the model, verify:

  • abs((d - r sin(theta))/l) <= 1 over the analyzed theta range
  • theta, beta, and trigonometric functions use radians in MATLAB
  • r, l, d, and v_B_y use consistent units
  • Positive velocity direction matches the plotted experimental collar velocity
  • The model is evaluated at the measured theta_exp, not only a separate model grid
  • Residuals are computed as signed differences using a stated convention

Important Limitation

This is a kinematic model. It predicts collar velocity from geometry and disk angular velocity. It does not model motor dynamics, friction, gravity, structural flex, or mechanical slack. Those effects should appear in the residual discussion, not as terms in the provided velocity equation unless the instructional team intentionally extends the model.

Model Equations - Locomotive Crank

Governing Kinematic Model

Use the geometric constraint:


sin(beta) = (d - r sin(theta)) / l

and:


beta = asin((d - r sin(theta)) / l)

The collar velocity model is:


v_mod = -omega r [sin(theta) + cos(theta) tan(beta)]

where:

  • v_mod is the modeled vertical collar velocity
  • omega is the measured disk angular velocity
  • theta is the measured disk angle
  • r is the disk-center-to-pin radius
  • l is the connecting-bar length
  • d is the horizontal offset from slide to disk center

Use radians for theta and beta.

MATLAB-Oriented Implementation


beta = asin((d - r .* sin(theta)) ./ l);
v_mod = -omega .* r .* (sin(theta) + cos(theta) .* tan(beta));

If r, l, and d are entered in centimeters, v_mod will be in centimeters per second when omega is in radians per second. If the experimental velocity is in millimeters per second, convert units before computing residuals.

Residual Definition

Use a signed residual and state the convention:


residual = v_exp - v_mod

Recommended statistics for each voltage:

  • mean residual
  • residual standard deviation
  • number of samples
  • notes about outliers or discarded startup/end effects

Expected Behavior

  • Higher motor voltage should increase the magnitude of disk angular velocity.
  • Higher disk angular velocity should increase the magnitude of collar velocity.
  • The shape of velocity versus theta should remain similar across voltage settings.
  • Residuals versus theta may show periodic structure due to mechanical play in the linkage.

The catalog procedure says students historically calibrated the potentiometer by measuring slide displacement and recording voltage at the highest and lowest collar positions. Expected calibration is approximately:

If calibration falls outside this range during live collection, the procedure recommends remeasuring the slide displacement and voltage endpoints.

Additional Notes - Locomotive Crank

Catalog Fit For ASEN 3501

This lab is a strong fit for model comparison and residual analysis because the governing model is geometric and accessible, while the real apparatus can still produce structured residuals through mechanical play, calibration offsets, and sign/unit mistakes.

The lab is less focused on experimental design unless students are asked to choose voltage cases, justify trimming rules, or propose improved instrumentation/procedure controls.

Student-Facing Emphasis

Recommended emphasis for ASEN 3501:

  • implement and verify a provided model
  • process measured data consistently
  • compare measured and modeled collar velocity
  • identify systematic residual structure
  • explain likely physical and measurement causes of mismatch

Avoid making the lab primarily about deriving crank-slider kinematics from scratch. Dynamics is prerequisite knowledge, but the course objective here is experimental methods and model-data comparison.

Instructor-Only Notes From Catalog

Common conceptual issues:

  • Students may try to include friction, gravity, mass, or inertia in a purely kinematic model.
  • The primary real-world error source is likely play/slop in the physical connections.
  • Residuals plotted versus theta are more revealing than residuals plotted only versus time.

Common procedural issues:

  • Not resetting the collar to the lowest position before starting the VI.
  • Exceeding 11 V on the supply.
  • Running the crank in the wrong direction.
  • Failing to use consistent units in MATLAB.
